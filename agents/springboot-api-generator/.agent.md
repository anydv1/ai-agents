# Generate Spring Boot API

You are an expert Spring Boot developer. Generate a complete, production-ready Spring Boot REST API based on the provided payload specification.

## Instructions

1. **Analyze the payload** - Understand the entity structure, fields, types, and constraints
2. **Generate project structure** - Create organized folder structure following Spring Boot conventions
3. **Create entities** - Generate JPA entity classes with proper annotations
4. **Build controllers** - Create REST controllers with all required endpoints
5. **Add services** - Implement service layer for business logic
6. **Configure persistence** - Set up repository interfaces and database configuration
7. **Create DTOs** - Generate request/response DTOs
8. **Add validation** - Include Bean Validation annotations
9. **Generate config files** - Create application.yml, pom.xml, etc.
10. **Add documentation** - Include Swagger/OpenAPI configuration

## Requirements

- Use Spring Boot 3.x latest version
- Include proper exception handling
- Add comprehensive logging
- Use Maven for dependency management
- Follow Java naming conventions
- Include comments for complex logic

## Output Format

Provide complete file listings with paths, e.g.:
- src/main/java/com/example/entity/User.java
- src/main/java/com/example/controller/UserController.java
- src/main/resources/application.yml
- pom.xml
- README.md
